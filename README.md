# Транслятор Java → C++

Проект преобразует поддерживаемое подмножество Java в файлы C++17 `.h` и `.cpp`.

Поддерживаются:
- классы и интерфейсы;
- поля, конструкторы и методы;
- `extends`, `implements`, `import` и `package`;
- `if/else`, `for`, `while`, `do-while`, `return`, локальные переменные;
- выражения, присваивания, арифметические, сравнительные и логические операции;
- постфиксные `++` и `--`;
- `new`, `this`, `null`, массивы.
- `System.out.println(...)`;
- базовый ввод через `java.util.Scanner`: `nextInt()`, `nextLine()`, `nextDouble()`, `close()`.

Диагностика выводится на русском языке и содержит стадию анализа, код ошибки, файл, строку и столбец.
Входные файлы проверяются на расширение `.java`, корректное имя, непустое содержимое и ограничение 10 000 строк.

Требования:
- Python 3.10 или новее;
- `pytest` для запуска тестов;
- `g++` для проверки компиляции сгенерированного C++ кода.

## Запуск CLI

```powershell
$env:PYTHONPATH = "src"
python -m java_cpp_translator.cli examples\Hello.java -o out
```

Результат будет записан в каталог `out`.

## Запуск GUI

```powershell
$env:PYTHONPATH = "src"
python -m java_cpp_translator.gui
```

В графическом интерфейсе можно выбрать входной `.java` файл, каталог вывода и выполнить трансляцию.
Окно показывает исходный код, русские сообщения диагностики и пути к созданным `.h/.cpp` файлам.

## Запуск тестов

```powershell
$env:PYTHONPATH = "src"
python -m pytest
```

## Структура проекта

- `src/java_cpp_translator` — исходный код транслятора;
- `src/java_cpp_translator/gui.py` — графический интерфейс;
- `examples/Hello.java` — пример входного файла;
- `tests/test_translator.py` — автоматические тесты;
- `test_plan.md` — план тестирования.

## Ограничения

Не поддерживаются `try/catch`, `switch`, аннотации, сложные generic-конструкции, `finalize()` и другие конструкции вне реализованного подмножества языка.
