# План тестирования транслятора Java → C++

Документ описывает набор проверок для лексического, синтаксического, семантического анализа и генерации C++ кода.

## Классы эквивалентности

| Область проверки | Корректный сценарий | Некорректный сценарий |
|---|---|---|
| Лексический анализ | Вход содержит только допустимые токены Java | Во входе присутствует недопустимый символ |
| Синтаксический анализ | Структура класса, интерфейса, методов и операторов соответствует поддерживаемой грамматике | Во входе нарушена грамматика |
| Области видимости | Все идентификаторы объявлены до использования | Использован необъявленный идентификатор |
| Объявление переменных | Имена переменных внутри одной области видимости уникальны | Переменная объявлена повторно |
| Типы условий | Условия `if`, `while`, `for` имеют тип `boolean` | В условии используется значение другого типа |
| Оператор `return` | Возвращаемое значение соответствует сигнатуре метода | Возвращаемое значение отсутствует или несовместимо |
| Неподдерживаемые конструкции | Вход содержит только реализованное подмножество Java | Во входе есть неподдерживаемая конструкция |
| Ссылочные типы | Ссылочные типы преобразуются в соответствующие типы C++ | Ссылочный тип преобразован неверно |
| Массивы | Массивы Java преобразуются в `std::vector` | Массивы преобразованы неверно |
| Генерация кода | Формируются корректные `.h` и `.cpp` файлы | Генерация неуспешна или результат не компилируется |

## Тест-кейсы

| ID | Проверка | Вход | Ожидаемый результат |
|---|---|---|---|
| TC-01 | Корректный лексический разбор | Java-файл с допустимыми токенами | Лексический анализ завершается без ошибок |
| TC-02 | Недопустимый символ | Символ `§` в исходном коде | Диагностика `InvalidCharacter` |
| TC-03 | Корректный синтаксический разбор | Интерфейс и класс с реализацией методов | Строится корректное синтаксическое дерево |
| TC-04 | Синтаксическая ошибка | Отсутствует разделитель или закрывающая скобка | Диагностика `SyntaxError` |
| TC-05 | Необъявленный идентификатор | Обращение к переменной без объявления | Диагностика `UndefinedIdentifier` |
| TC-06 | Повторное объявление | Повторное объявление переменной в одном блоке | Диагностика `DuplicateVariable` |
| TC-07 | Некорректный тип условия | `if (1)` | Диагностика `TypeMismatch` |
| TC-08 | Некорректный `return` | `void`-метод возвращает значение | Диагностика `InvalidReturn` |
| TC-09 | Неподдерживаемая конструкция | `try/catch` | Диагностика `NotSupported` или эквивалентная ошибка синтаксиса |
| TC-10 | Ссылочные типы | Поле пользовательского типа, `String`, `null` | Генерируются `std::shared_ptr`, `std::string`, `nullptr` |
| TC-11 | Массивы | `int[] arr = new int[n];` | Генерируется `std::vector<int>` |
| TC-12 | Компиляция результата | Корректный входной класс | Сгенерированный код компилируется `g++ -std=c++17` |

## Автоматические тесты

Проверки реализованы в `tests/test_translator.py`.

Автоматически проверяются:
- успешная генерация `.h` и `.cpp`;
- ошибки лексического, синтаксического и семантического анализа;
- преобразование `String`, пользовательских классов, `null` и массивов;
- компиляция части сгенерированного кода при наличии `g++` в окружении.
